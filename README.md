# Lumi - Svet plný zábavy

Statická HTML5 aplikácia pre VIKI/CUDEO balík. Dá sa otvoriť cez `index.html` bez build kroku a bez externých knižníc.

## Obsah

- výber profilu dieťaťa s premenovaním a voľbou z 8 Lumi avatarov,
- mapa Sveta plného zábavy s 20 krokmi,
- freemium logika: kroky 1-8 otvorené, kroky 9-20 za rodičovskou bránou,
- interaktívne typy úloh podľa zadania,
- abecedná nápoveda s 34 obrazovými kartičkami a návratom do úlohy,
- minihra Lumikové prekvapenia,
- lokálne ukladanie progresu cez `localStorage`,
- optimalizované assety v podporovaných formátoch PNG/JPG vrátane transparentných Lumi póz.

## VIKI parametre

- vstupný súbor: `index.html`,
- responzívne od 320x560 po 1920x1080,
- bez CDN a sieťových závislostí,
- celý pracovný balík je výrazne pod 10 MB,
- obsah je HTML5 black-box.

## Produkčné poznámky

Finálne vydanie má nahradiť Web Speech API skutočnými MP3 nahrávkami a pripojiť licenčný backend pre limit 3 zariadení na Google konto.
